# Responsive Laundry Services Web App

An updated, fully responsive version of the laundry service web application, built using CSS Flexbox, CSS Variables, and Media Queries to ensure a seamless experience across desktop, tablet, and mobile screens[cite: 7].

## 📋 Features & Requirements
- **CSS Variables:** Utilizes custom properties (`:root`) for easy theme and color management.
- **Responsive Navbar:** Built with Flexbox. Automatically scales text sizes for tablets and hides navigation links on mobile viewports (showing only the logo and username)[cite: 7].
- **Adaptive Hero Section:** Uses `flex-direction` changes and media queries to rearrange the layout into a neat column format on smaller screens, optimizing text and image sizes[cite: 7].
- **No Overflow/Scroll Issues:** Clean mobile and tablet wrapping to prevent horizontal scrolling.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Media Queries, CSS Variables)[cite: 7]
